## 关键技术事实（供后续复用）

- 秒杀链路：Lua 原子预检(0成功/1库存不足/2重复/-1缺key) → rabbitTemplate.convertAndSend → 消费者 Redisson 锁 + 乐观锁 stock>0 落库。
- 缓存：queryWithPassThrough(空值缓存TTL2min) + queryWithLogicalExpire(互斥锁+10线程池异步重建)；更新走 Cache Aside(先写库后删缓存)。
- 分布式锁演进：setnx → 带TTL → 线程标识 → Lua释放(unlock.lua) → Redisson(可重入+看门狗)。
- 全局ID：RedisIdWorker = 相对时间戳(2022-01-01)<<32 | 当天Redis自增。
